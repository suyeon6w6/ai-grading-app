# 서논술형 답안 자동 채점 웹앱

## 파일 구성
- `app.py` — Streamlit 메인 앱 (UI)
- `grading_data.py` — 세트1~3, 문항1~3의 채점 기준 데이터 (필수 키워드, 오답 패턴, 대비 요소 등)
- `grading_engine.py` — 채점 로직 (의미 요소 매칭, 관계 단위 매핑, 방향/중복/외부지식 감지)

## 실행 방법
```bash
pip install streamlit
streamlit run app.py
```

## 채점 로직 핵심 규칙 반영 내역
1. **용어 없이 의미만 있어도 인정**: `grading_data.py`의 각 `required` 항목은 동의어 리스트(그룹)로
   구성되어 있어, 지문 표현 그대로가 아니어도 의미가 같은 단어가 있으면 통과합니다.
2. **선택한 설명 방법의 특성이 답안에 드러나야 함**: 문항2에서 괄호 속 방법명과 실제 문장의
   판별 신호(cue phrase, `METHOD_CUES`)를 대조합니다. 신호가 전혀 없으면 자동 오답 대신
   `"명칭-서술 불일치 의심"` 플래그를 띄워 채점자 확인을 요청합니다(오탐 방지를 위해 자동 확정하지 않음).
3. **선택지가 있는 문항의 모범 답안 전체 제시**: 문항2 화면 하단에 세트별로 실제로 성립 가능한
   설명 방법(정의/예시/인과/비교와 대조 등, 지문 내용상 성립되지 않는 방법은 제외)의 모범 문장을
   모두 제시합니다.
4. **오개념 방지(방향 뒤바뀜 감지)**: 문항2는 문장을 관계 단위(U1/U2, V1/V2, W1/W2)에 매핑하고,
   조건은 A단위인데 방법은 B단위에 해당하는 등 뒤섞인 경우 자동 오답 처리합니다.
   문항1도 반대 방향 키워드(`reversal`)가 감지되면 즉시 미충족 처리합니다.
5. **결론 방향 확인**: 세트3 문항1 ㉡처럼 결론+근거를 모두 요구하는 문항은 `dual_requirement`로
   표시되어 있으며, 결론이 지문과 반대 방향(`conclusion_reversal`)이면 근거 서술 여부와 무관하게
   즉시 미충족 처리합니다. 문항3도 "장면1과 대비" 요건을 `contrast_forbidden` 키워드로 검사합니다.

## 주의사항 (자동 채점의 한계)
이 앱은 **규칙 기반 키워드/패턴 매칭**입니다. 다음의 경우는 정확도가 떨어질 수 있어
"1차 스크리닝 + 교사 최종 확인"으로 사용하는 것을 권장합니다.
- 완전히 새로운 표현이나 은유로 서술된 답안
- 문법은 맞지만 의미가 미묘하게 다른 답안
- 여러 조건이 복합적으로 얽힌 장문 답안

앱 내 "명칭-서술 불일치 의심" 등 경고(⚠️) 표시가 뜨는 답안은 반드시 사람이 재확인하세요.
